# Projects

## 1. MovieGraph

### Overview

MovieGraph is a full-stack movie management and recommendation
application that uses graph-based relationships to connect movies,
persons, and genres.

The application provides REST APIs through Spring Boot and a React
frontend for interacting with the application.

### Technologies Used

- Java
- Spring Boot
- React
- REST APIs
- Graph Database
- JavaScript
- HTML
- CSS

### Features

- Movie CRUD operations
- Person management
- Genre management
- Graph-based relationships
- Movie recommendations
- REST API integration
- Interactive frontend
- Swagger API documentation

### Graph Relationships

The application represents relationships between different entities:

- ACTED_IN
- DIRECTED
- HAS_GENRE

These relationships are used to connect movies with actors,
directors, and genres.

### Implementation

#### Frontend

The frontend was developed using React.

The frontend communicates with the backend through REST APIs and
provides interfaces for managing movies, persons, and genres.

#### Backend

The backend was developed using Spring Boot.

REST endpoints were created for performing CRUD operations and
retrieving related movie information.

#### Database

A graph database is used to represent relationships between movies,
persons, and genres.

This structure makes it possible to traverse relationships and
retrieve connected movie information.

#### Recommendation

The recommendation functionality uses graph relationships to find
movies connected through common actors, directors, and genres.

#### Deployment

- Frontend: Vercel
- Backend: Render

# 3. Bone Fracture Detection System

## Overview

Bone Fracture Detection System is a machine learning project designed
to identify possible bone fractures from X-ray images.

### Technologies Used

- Python
- Convolutional Neural Network (CNN)
- Image Processing
- Machine Learning

### Features

- X-ray image processing
- Image preprocessing
- CNN-based classification
- Data augmentation
- Fracture detection

### Implementation

X-ray images are preprocessed before being provided to the CNN model.

Image preprocessing and augmentation are used to improve the quality
and variety of training data.

The CNN model learns visual patterns from the X-ray images and
classifies them based on the trained model.
